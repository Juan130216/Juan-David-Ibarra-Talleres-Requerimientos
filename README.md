# Evaluador de Requisitos SMART-V

Este repositorio contiene un script interactivo en Python diseñado para evaluar la calidad de los requerimientos de software utilizando el modelo **SMART-V**.

## Criterios de Evaluación
- **Específico (S):** Evita adjetivos ambiguos o vagos.
- **Medible (M):** Contiene métricas numéricas o porcentajes.
- **Alcanzable (A):** Excluye falsas promesas o expectativas irrealistas.
- **Relevante (R):** Identifica un rol de negocio o propósito claro.
- **Identificable (I):** Sigue una nomenclatura estandarizada (ej. `REQ-001`).
- **Verificable (V):** Define condiciones o restricciones comprobables.

## Uso
Ejecuta el archivo `evaluador.py` en tu entorno local de Python para probar requerimientos en tiempo real desde la consola.
